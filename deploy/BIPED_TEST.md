# 二足を実機で試す手順

このファイルだけを見れば試せるように書いてあります。上から順に進めてください。

- 方策:HoldBall-Switch c1 です。二足で立ち、歩き、前腕に物を載せて持ちます。
- 二足の間は、止まっていても足踏みします。
- 四足に下りるときは、0.5 秒の決めた動きで下ります。
- 床がカーペットのように柔らかいと、立っているときの傾きが変わり、勝手に前へ進みやすくなります。シミュレーターでは、傾きが 3° ずれると 0.3 m/s 進みました。できれば硬い床で試してください。

## 1. 始める前に確かめる

- 周りの 2 m に人や物がないこと。
- バッテリーが十分あること。
- リモコンの電源が入っていること。
- ロボットが床に伏せていること。
- 胴体のひも、ハーネスを持つ人が一人いること。

## 2. ネットワークを Go2 に切り替える

1. インターネットのケーブルを抜いて、Go2 のケーブルを挿します。
2. 端末で次を実行します。
   ```bash
   nmcli con up go2
   ```
3. 次を実行して、返事が3回返ってくることを確かめます。
   ```bash
   ping -c 3 192.168.123.161
   ```

## 3. 起動する

端末で次を実行します。
```bash
cd ~/pai_final && ~/go2_sim2real/.venv/bin/python deploy/go2_real.py --mode real --iface eno1 --export_dir logs/rsl_rl/unitree_go2_biped_holdball_switch/2026-10-31_00-25-13_holdball_switch_c1/exported
```
傾きの補正は −5.0° です。10-31 にカーペットの床で L1 / R1 で決めた値です。二足で立ち上がってから 3 秒かけて 0 から −5.0° になります。最初から −5.0° だと、立ち上がりで後ろに傾きました。画面の `trim` の値で確かめられます。別の値で始めたいときは、最後に `--pitch_trim <値>` を付けます。

## 4. リモコンの操作

| ボタン・スティック | 動き |
|---|---|
| select | 脱力して伏せる。非常停止 |
| start | 四足で立つ |
| A / 十字キー上 | 二足で立つ |
| 十字キー下 | 四足に下りる |
| 左スティック 前後 | 前進・後退。最大 0.64 m/s |
| 左スティック 左右 | 横歩き。最大 0.4 m/s |
| 右スティック 左右 | 旋回。最大 1.2 rad/s |
| L1 / R1 | 傾きの補正を 0.5° ずつ変える。L1 で後ろへ、R1 で前へ進みやすくなる。最初は −5.0° |
| B | 四足に下りてから、伏せて立ち直す |
| Y、二足のとき | 撮影用の決まった動き、約 34 秒:左に旋回 → 右に旋回 → 前 → 後ろ → 左へ横 → 右へ横。間に 2 秒ずつ止まる。行って戻るので、ほぼ元の場所に戻る。スティックを触るか、もう一度 Y で止まる |

最大は、物を持っているときに学習で練習した範囲です。倒した分だけ速くなります。ほんの少しだけ倒すと、止まれの指示になります。

## 5. 試験1:二足で立って、四足に下りる

1. 起動して、`yes` と入力します。ロボットが伏せて脱力し、`ready` と出ます。
2. **select** を押します。`[OK]` と出ます。
3. **start** を押します。四足で立ちます。
4. ハーネスを持ちます。
5. **A** を押します。二足で立ち、その場で足踏みします。
6. 10 秒見ます。前へ進み続けるなら **L1**、後ろへ進み続けるなら **R1** を1回押します。少し前後に行ったり来たりするのは、今の方策のくせで、補正では止まりません。進みすぎたら、左スティックで戻します。
7. **十字キー下** を押します。四足に下ります。
8. **十字キー上** を押して二足に立ち、**十字キー下** で四足に下ります。これを3回繰り返します。
9. **select** を押します。伏せて脱力します。
10. 端末で **Ctrl-C** を押して終わります。

## 6. 試験2:歩く

1. 3 のコマンドで起動します。
2. `yes` → **select** → **start** → ハーネスを持つ → **A** の順に進めます。二足で立ちます。
3. 左スティックを前に倒して 3 秒待ち、離します。
4. 右スティックを左に倒して 3 秒待ち、離します。右にも同じようにします。
5. 左スティックを後ろに倒して 3 秒待ち、離します。
6. **十字キー下** → **select** → **Ctrl-C** の順に押します。

## 7. 試験3:前腕に荷物を載せる

1. 3 のコマンドで起動します。
2. `yes` → **select** → **start** → ハーネスを持つ → **A** の順に進めます。二足で立ちます。
3. 別の人が、大きい球か広い箱を、1 kg くらいから、前腕にそっと載せます。
4. 10 秒持たせます。進むときは、スティックで止めます。
5. 荷物を手で取ります。荷物を持っている間は、十字キー下を押しても下りません。
6. **十字キー下** → **select** → **Ctrl-C** の順に押します。

## 8. 困ったとき

- **危ないと感じたら、すぐ select を押します。** 脱力して伏せます。
- モーターが 70 °C になると、自動で四足に下ります。冷えるまで A は効きません。
- 端末に `eno1: does not match an available interface` と出たら、`nmcli con up go2` をやり直します。
- B を押すと、四足に下りてから伏せて、立ち直します。

## 9. 終わったら

1. Go2 のケーブルを抜いて、インターネットのケーブルを挿します。
2. 端末で次を実行します。
   ```bash
   nmcli con up "Wired connection 1"
   ```
3. 記録は `deploy/real_logs/` に残っています。Claude に「終わった」と伝えます。
